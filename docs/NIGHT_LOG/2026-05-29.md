  orchestrator built X. With a `docs/PLAN.md` in place, future
  sessions can dispatch against named units.
- **Don't pre-build specialists.** Custodian, Hammer, Tava, Patron,
  Counter, Mirror all have prompt files; only Sentry +
  ServiceArchitect ran. Spur's rule "add when friction appears" is
  right.
- **Escalate explicit decisions instead of guessing.** Branch name
  picks, Slack-vs-iMessage routing, "is the printer Star or Epson"
  — these should have gone in `docs/AGENT_QUESTIONS.md` instead of
  being decided inline.

  fell out of sync with the real local repo once. The convention
  `.agent-org/worktrees/<role>-<slug>/` from PROTOCOL.md should be
  followed every time.
